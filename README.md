# Novexxa Bank — Demo Starter

A responsive, front-end banking dashboard prototype for **demo/testing only**.

## Included
- Overview dashboard with illustrative USD balance and sample transaction history
- Sidebar navigation and mobile hamburger menu
- Account status displayed as **INACTIVE**
- Demo transfer and withdrawal forms
- Country/provider selector with examples for Portugal, Germany, France, the UK, US, Nigeria, Ghana, Kenya, South Africa, and other regions
- Verification-code modal for demo flow
- Demo card, support form, and settings screens

## Preview
Open `index.html` in a browser, or enable GitHub Pages in the repository settings and select the `main` branch with the `/(root)` folder.

## Demo-only security notes
- The preview code `246810` is hardcoded in browser JavaScript and is **not secure**.
- No real transfers, withdrawals, cards, balances, or support messages are connected.
- Do not enter real bank credentials or sensitive personal information.
- Before any real account system is used, implement server-side verification, Supabase Auth, database tables, row-level security policies, server-side authorization, rate limiting, audit logging, and secure handling of secrets. Never put service-role keys or other secrets in browser code.
- Keep all demo balances clearly labeled as simulated funds.

This repository is a starter interface, not a licensed bank or production financial service.
