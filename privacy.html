Privacy Policy

Last updated: October 21, 2026

Demo only: Novexxa is not a licensed bank. Do not enter real bank-account credentials, payment-card details, government ID numbers, or other sensitive information.

1. Information entered

If you create a demo account, the website may process the legal name, username, email address, phone number, country, selected demo account type, password-authentication data, and a four-digit transaction PIN you provide. Demo actions may also create account, support, or transaction-request records.

2. How it is used

This information is used to create and manage your demo account, authenticate sign-in, show the selected account settings, and test the site's simulated features.

3. Authentication and PIN security

Sign-in passwords are handled by Supabase Authentication. The transaction PIN is sent to the server-side database function for hashing; the website is designed not to store the PIN as plain text in the profile table. Never reuse an important real-world PIN or password in a demo.

4. Service provider

The demo uses Supabase for authentication and database storage. Information you submit may be processed and stored by the project's Supabase infrastructure according to its configuration and applicable provider terms.

5. Sharing and disclosure

This demo is not designed for real financial transactions. Do not submit information you cannot risk exposing in a test environment. Access to stored records may be available to authorized project administrators for maintenance and testing.

6. Retention and deletion

Demo records may remain in the database until an authorized project administrator deletes them. The current website does not provide a self-service data deletion control. Contact the project owner through the channel where you received this demo if you need a record reviewed or removed.

7. Security

Reasonable technical controls are configured for this demonstration, but no online system can be guaranteed perfectly secure. Do not use this demo as a real bank account or submit highly sensitive data.

8. Changes

This policy may be updated as the demo changes. The date above indicates the latest stated revision.
